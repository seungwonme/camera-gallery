# Camera Framing Atlas

개인 GitHub Pages로 공개하는 카메라 프레이밍/렌즈/환경 개념 갤러리입니다.

- Live site: https://seungwonme.github.io/camera-gallery/
- Repository: https://github.com/seungwonme/camera-gallery
- Scope: `camera-map-framing.json`의 33개 항목
- Renderer: 브라우저 Canvas 2D로 직접 그리는 정적 도식

## 범위와 제한

원본 영화, 광고, GIF, 촬영 파일을 복제하지 않습니다. 휴머노이드, 카메라, 격자, 가림막, 입자와 광학 효과는 개념 설명을 위한 독립 도식입니다. 어안, 틸트 시프트, 망원 압축, 전방위 재투영과 수중 효과는 정확한 광학 시뮬레이션이 아닙니다.

`Wide Close-up`, `Close Shot`, `Medium Close Shot`은 원자료의 경계가 충분히 정의되지 않아 갤러리에서 선택한 해석을 매핑 설명에 공개합니다.
